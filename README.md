# HR Analytics – Employee Attrition (Python Project)

## Overview

This project analyzes employee data to understand why employees leave a company and what factors are linked to attrition.

The main goal is to identify patterns that can help HR teams reduce employee turnover and improve retention.

## What this project focuses on

* Understanding employee attrition patterns
* Identifying key factors behind employee resignation
* Exploring relationships between salary, job satisfaction, and turnover
* Building simple predictive insights using data analysis

## Tools used

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Scikit-learn (basic modeling)
* Jupyter Notebook

## Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Attrition pattern analysis
5. Feature relationship study
6. Basic prediction modeling

## Key insights

* Lower salary groups show higher attrition rates
* Job satisfaction has a strong relationship with employee retention
* Overtime employees are more likely to leave
* Certain departments show higher turnover than others
